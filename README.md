# Организация услуг · Account Manager

Внутренняя страница аккаунт-команды: интерфейс со скриптами и справочниками,
данные — из Grist, обновляются автоматически.

## Как это устроено

```
Grist (team.agilefluent.co)
   │  GitHub Actions, cron каждые 15 минут (ключ — в секретах репозитория)
   ▼
scripts/sync-grist.mjs  →  public/data.enc   (данные, AES-256-GCM)
                           public/app.enc    (интерфейс, собирается локально)
   ▼
GitHub Pages  →  https://sashaolei.github.io/account-manager-page/
   ▼
index.html: спрашивает пароль → расшифровывает → показывает интерфейс,
            раз в 3 минуты подтягивает свежий data.enc
```

Репозиторий публичный — на тарифе GitHub Free Pages иначе не работает.
Поэтому наружу не выкладывается ничего читаемого: и интерфейс, и данные лежат
зашифрованными (AES-256-GCM, ключ выводится из пароля через PBKDF2, 250k
итераций). Картинки и видео вшиты внутрь зашифрованного интерфейса, отдельными
файлами не лежат. Исходник интерфейса, матрица экспертов в открытом виде и
тестовый снапшот данных в репозиторий не попадают вообще — см. `.gitignore`.

Ключ Grist в браузер не попадает: запросы к Grist делает раннер GitHub Actions,
ключ живёт только в секретах репозитория.

## Что тянется из Grist

| Таблица | Фильтр | Куда попадает |
|---|---|---|
| `Team` | `Role` = Recruiter или Searcher, `Retired` = false | «Эксперты» (Recruiter), «Серчеры» (Searcher), прогресс по ЗП |
| `Zite_Fillout_Links` | всё | «Fillout» |
| `Commitments` | `Status` = Execution или On Pause | «Активные клиенты», группировка по `Team_Active` (у клиентов на паузе — по `Team`) |

Продукты разворачиваются из ссылок на таблицу `Products` (поле `Tag`).
Отпуска парсятся из строки `Vacations` («14.09.26 — 21.09.26, …»).

Матрица экспертов (роли, индустрии, страны экспертизы) в Grist не хранится: она
лежит в `src/matrix.enc` (шифром) и мержится по имени. Обновляется правкой
`src/matrix.json` локально + `npm run build`, либо, как и раньше, загрузкой CSV
прямо в интерфейсе.

## Что нужно на GitHub

Два секрета (Settings → Secrets and variables → Actions):

- `GRIST_API_KEY` — ключ Grist
- `PAGE_PASSPHRASE` — пароль, который команда вводит на странице

Pages: Settings → Pages → Source: **GitHub Actions**.

## Обновления

- **Данные** — сами, раз в 15 минут. Кнопка «обновить» в правом нижнем углу
  страницы тянет свежий `data.enc` немедленно.
- **Интерфейс** — положить новый экспорт в `src/app-source.html`, затем:
  ```bash
  PAGE_PASSPHRASE=<пароль> npm run build
  git add public/app.enc src/matrix.enc && git commit -m "новый интерфейс" && git push
  ```
- **Пароль** — сменить секрет `PAGE_PASSPHRASE`, пересобрать `app.enc` с новым
  паролем (команда выше) и запушить. Иначе интерфейс останется на старом пароле,
  а данные будут шифроваться новым.

## Локальный запуск

```bash
npm install
PAGE_PASSPHRASE=<пароль> npm run build       # app.enc + matrix.enc
PAGE_PASSPHRASE=<пароль> npm run sync:local  # data.enc из снапшота, без Grist
npx http-server public -p 8099
```

`GRIST_API_KEY=... PAGE_PASSPHRASE=... npm run sync` соберёт `data.enc` из живого
Grist (нужен доступ к team.agilefluent.co). `npm test` — два теста: выгрузка из
фейкового Grist (проверяет преобразование полей) и прогон страницы в
headless-браузере (проверяет, что все четыре таблицы наполняются).

Открывать `public/index.html` как файл (`file://`) нельзя: WebCrypto работает
только на https или localhost.

## Что стоит знать

- Cron в GitHub Actions неточен: реальная задержка обычно 15–20 минут. Если
  репозиторий не трогать 60 дней, GitHub отключает расписание — достаточно
  запустить workflow руками.
- `public/app.enc` (~5 МБ) лежит в репозитории и меняется только при пересборке
  интерфейса, поэтому браузер отдаёт его из кэша: тяжёлой первая загрузка будет
  один раз.
- В интерфейсе есть две правки относительно исходного экспорта: данные берутся
  из `window.__AM_DATA` вместо локальных `.js`-модулей, и чинится `<sc-for>`
  внутри `<tbody>` — HTML-парсер браузера выбрасывает его из таблицы, из-за чего
  в исходном файле все четыре таблицы рендерились пустыми.
- Нужен настоящий realtime и вход по вашей авторизации вместо пароля — страницу
  надо переносить на свой бэкенд: один роут отдаёт `public/`, второй — JSON из
  `GristRepo` (логика преобразования готова: `scripts/transform.mjs`, чистая
  функция без зависимостей).

## Структура

```
public/index.html       лоадер: пароль, расшифровка, автообновление
public/app.enc          зашифрованный интерфейс со вшитыми картинками (в репозитории)
public/data.enc         зашифрованные данные (генерирует Actions, не коммитится)
scripts/build-app.mjs   сборка и шифрование интерфейса
scripts/sync-grist.mjs  выгрузка из Grist и шифрование данных
scripts/transform.mjs   преобразование записей Grist в формат интерфейса
scripts/grist.mjs       клиент Grist API
scripts/crypto.mjs      шифрование/расшифровка
src/matrix.enc          матрица экспертов (шифром)
test/                   тесты
```

Локально (в `.gitignore`, в репозиторий не уходит): `src/app-source.html`,
`src/assets/`, `src/matrix.json`, `src/support.js`, `src/react*.js`,
`src/*-data.js` и остальной снапшот на 04.08.26.
